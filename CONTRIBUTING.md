# Contributing to Gyaan RAG

Thank you for your interest in contributing to Gyaan RAG.

## How to Contribute

1. **Fork** the repository on GitHub
2. **Clone** your fork locally: `git clone https://github.com/YOUR-USERNAME/Gyaan-Rag.git`
3. **Create a branch**: `git checkout -b feat/your-feature-name`
4. **Make changes** — keep them focused and well-documented
5. **Test** your changes locally: start the server and verify behaviour
6. **Commit** with a clear message: `git commit -m "feat: what you changed"`
7. **Push** your branch: `git push origin feat/your-feature-name`
8. **Open a Pull Request** with a description of what and why

## Code Style

- Python: follow PEP 8; use type hints where practical
- JavaScript: vanilla ES modules; no build step required
- Keep PR scope small and focused

## Security

**Never include API keys, tokens, or secrets in commits or PRs.**

All credentials must go in `.env` (which is `.gitignore`d).

## Reporting Issues

Open a GitHub Issue with:
- A clear description of the problem
- Steps to reproduce
- Expected vs. actual behaviour
- Environment details (OS, Python version)
